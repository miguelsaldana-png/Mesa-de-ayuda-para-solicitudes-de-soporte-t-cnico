##  Propósito del Sistema

Aplicación web desarrollada en **C\# y Blazor** diseñada para registrar, organizar y dar seguimiento centralizado a las solicitudes de soporte técnico en una tienda con múltiples sucursales, reemplazando la gestión desordenada mediante chats o notas de voz.
